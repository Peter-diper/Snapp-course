# پروژه اسنپ 🚕

🇬🇧 [English Version](README.md)

یک صفحه وب با الهام از وب‌سایت اسنپ که به عنوان یک پروژه عملی در دوره آموزش توسعه وب ساخته شده است.

این پروژه با هدف تمرین و پیاده‌سازی مفاهیم توسعه فرانت‌اند و ساخت یک رابط کاربری مشابه یک وب‌سایت واقعی انجام شده است.

## ✨ ویژگی‌ها

- صفحه اصلی با الهام از طراحی اسنپ
- طراحی واکنش‌گرا (Responsive)
- نوار ناوبری
- بخش Hero
- بخش‌های مختلف خدمات
- پشتیبانی از زبان فارسی و راست‌چین (RTL)
- استایل‌دهی اختصاصی رابط کاربری
- سازگاری با موبایل

## 🛠️ تکنولوژی‌های استفاده‌شده

- HTML5
- CSS3
- JavaScript

## 📂 ساختار پروژه

```text
Snapp-course/
├── src/
├── index.html
├── text.html
├── README.md
└── README.fa.md
```

## 🚀 اجرای پروژه

ابتدا مخزن را Clone کنید:

```bash
git clone https://github.com/Peter-diper/Snapp-course.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd Snapp-course
```

در نهایت فایل `index.html` را با مرورگر خود باز کنید.

این پروژه برای اجرا به نصب هیچ وابستگی یا پکیج اضافی نیاز ندارد.

## 🎯 هدف پروژه

هدف اصلی این پروژه تمرین توسعه فرانت‌اند از طریق بازسازی ساختار و ظاهر یک وب‌سایت واقعی بوده است.

این پروژه به عنوان بخشی از یک دوره عملی آموزش توسعه وب و به صورت پروژه‌محور با یکی از دانش‌آموزان انجام شده است.

## 📚 مهارت‌های تمرین‌شده

- ساختاردهی صفحات وب با HTML
- ایجاد Layoutهای واکنش‌گرا با CSS
- پیاده‌سازی رابط‌های راست‌چین (RTL)
- سازمان‌دهی فایل‌های پروژه فرانت‌اند
- بازسازی رابط کاربری وب‌سایت‌های واقعی
- تبدیل یک طراحی به یک صفحه وب کاربردی
