# Snapp Course 🚕

🇮🇷 [نسخه فارسی](README.fa.md)

A Snapp-inspired landing page built as a practical frontend project during a web development course.

This project was created as a hands-on exercise to practice building a real-world interface using HTML, CSS, and JavaScript.

## ✨ Features

- Snapp-inspired landing page
- Responsive layout
- Navigation bar
- Hero section
- Service sections
- Persian (RTL) interface
- Custom UI styling
- Mobile-friendly design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Peter-diper/Snapp-course.git
```

Navigate to the project directory:

```bash
cd Snapp-course
```

Then open `index.html` in your browser.

No additional dependencies or installation are required.

## 🎯 Purpose

The purpose of this project was to practice frontend development by recreating the structure and visual style of a real-world website.

The project was developed as part of a practical web development course and completed as a hands-on project with a student.

## 📚 What I Practiced

- Structuring web pages with HTML
- Creating responsive layouts with CSS
- Working with RTL interfaces
- Organizing frontend project files
- Recreating real-world UI designs
- Translating a design into a functional webpage
